# সারা মনি মেডিসিন কর্নার (SaramoniPOS) — ফার্মেসি ম্যানেজমেন্ট ওয়েব ও PWA অ্যাপ্লিকেশন

**সারা মনি মেডিসিন কর্নার (SaramoniPOS)** হলো একটি আধুনিক, অফলাইন-ফার্স্ট, রিয়েল-টাইম সিঙ্কড এবং এন্ড-টু-এন্ড এনক্রিপ্টেড (AES-256-GCM) বাংলা ও ইংরেজি ফার্মেসি পরিচালনা সিস্টেম। এটি ডেস্কটপ, ট্যাবলেট এবং মোবাইলে PWA (Progressive Web App) হিসেবে ইনস্টল করে ব্যবহার করা যায় এবং GitHub, Docker, VPS বা Kubernetes ক্লাস্টারে সহজেই হোস্ট করা যায়।

---

## প্রধান ফিচারসমূহ (Key Features)

1. **সমন্বিত ড্যাশবোর্ড ও দ্রুত POS বিলিং**:
   - আজকের মোট বিক্রি, নিট লাভ, গড় লাভের হার, প্রদত্ত ডিস্কাউন্ট এবং স্টক/মেয়াদ সতর্কতা এক স্ক্রিনে।
   - ওষুধের নাম, জেনেরিক নাম ও **ব্যাচ নম্বর** অনুযায়ী তাৎক্ষণিক সার্চ।
   - প্রতি আইটেমের **কিনা দাম**, **বিক্রি দাম**, **ডিস্কাউন্ট (%)** এবং লাইভ **নিট লাভ** হিসাব।
2. **অটোমেটেড ইনভয়েস জেনারেটর**:
   - বিল সেভ করার সাথে সাথেই অটো-ইনভয়েস তৈরি হয় (ইনভয়েস নম্বর, তারিখ, ক্রেতার তথ্য, ব্যাচ, ডিস্কাউন্ট, ভ্যাট, নগদ/বিকাশ/নগদ/কার্ড/বাকি পেমেন্ট স্ট্যাটাস)।
   - এক ক্লিকে প্রিন্ট/PDF সেভ এবং অফলাইন HTML রিসিট ডাউনলোড।
3. **পূর্ণাঙ্গ ইনভেন্টরি ও অ্যালার্ট সেন্টার**:
   - ব্যাচ ভিত্তিক স্টক, ন্যূনতম স্টক সতর্কতা (Low Stock Alert) এবং মেয়াদ উত্তীর্ণ হওয়ার সতর্কতা (Expiry Alert)।
   - মেয়াদোত্তীর্ণ ওষুধ POS-এ বিক্রি স্বয়ংক্রিয়ভাবে ব্লক থাকে।
4. **কাস্টমার ডাটাবেজ ও বকেয়া খাতা**:
   - কাস্টমারের মোট ক্রয়, ভিজিট সংখ্যা, বকেয়া ব্যালেন্স ও আদায়, এবং ক্রয় ইতিহাস।
5. **রিয়েল-টাইম সিঙ্ক ও অফলাইন মোড (PWA + IndexedDB)**:
   - ইন্টারনেট সংযোগ না থাকলেও ব্রাউজারের IndexedDB এবং Service Worker-এর মাধ্যমে নির্বিঘ্নে বিলিং ও ইনভেন্টরি আপডেট চলে।
   - ইন্টারনেট ফিরে এলে পেন্ডিং মিউটেশনগুলো স্বয়ংক্রিয়ভাবে `/api/sync/batch`-এর মাধ্যমে সার্ভারে সিঙ্ক হয় এবং WebSocket (`/ws`) দিয়ে সব ডিভাইসে রিয়েল-টাইম আপডেট পৌঁছে যায়।
6. **এন্ড-টু-এন্ড এনক্রিপশন (AES-256-GCM) ও ডাটা ব্যাকআপ**:
   - Web Crypto API (`PBKDF2-SHA256` + `AES-256-GCM`) ব্যবহার করে কাস্টমারের সংবেদনশীল মেডিকেল নোট ও ব্যাকআপ ফাইল (`.apharma`) এনক্রিপ্ট করা যায়।
7. **মাল্টি-ল্যাঙ্গুয়েজ, ডার্ক মোড ও কাস্টমাইজেশন**:
   - ডিফল্ট **বাংলা** এবং তাৎক্ষণিক **English** ভাষা পরিবর্তন।
   - লাইট/ডার্ক মোড, কমপ্যাক্ট/আরামদায়ক টেবিল ডেনসিটি এবং ফার্মেসির নাম, লাইসেন্স, ভ্যাট ও সতর্কতা সীমা কাস্টমাইজেশন।

## লোকাল ডেভেলপমেন্ট ও রান করার নিয়ম

### প্রয়োজনীয় সফটওয়্যার
- Node.js `v22+` এবং `npm`

### ইনস্টল ও চালু করা
```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/your-username/arogyapos.git
cd arogyapos

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. এনভায়রনমেন্ট ফাইল তৈরি করুন (ঐচ্ছিক)
cp .env.example .env

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন (Port 3000)
npm run dev
```

ব্রাউজারে `http://localhost:3000` ওপেন করুন।

### প্রোডাকশন বিল্ড ও রান
```bash
npm run build
NODE_ENV=production npm start
```

## GitHub ও পার্সোনাল হোস্টিং (Docker / VPS)

আপনি কোডটি GitHub-এ পুশ করে যেকোনো Linux VPS বা পার্সোনাল সার্ভারে Docker দিয়ে চালাতে পারেন:

```bash
docker compose up -d --build
```

- অ্যাপ চলবে `http://<server-ip>:3000` পোর্টে।
- SQLite ডাটাবেজ `arogyapos_data` ভলিউমে স্থায়ীভাবে সংরক্ষিত থাকবে।

## Kubernetes (K8s) ডিপ্লয়মেন্ট গাইড

প্রজেক্টের `k8s/` ডিরেক্টরিতে প্রোডাকশন-রেডি ম্যানিফেস্ট দেওয়া আছে:

- `k8s/configmap.yaml`: পোর্ট ও `DATA_DIR` কনফিগারেশন।
- `k8s/pvc.yaml`: SQLite ডাটাবেজের জন্য `5Gi` পার্সিস্টেন্ট ভলিউম।
- `k8s/deployment.yaml`: সিঙ্গেল-রাইটার `Recreate` স্ট্র্যাটেজি, `/api/health` ও `/api/ready` প্রোব।
- `k8s/service.yaml`: ClusterIP সার্ভিস (Port `80 -> 3000`)।
- `k8s/ingress.yaml`: WebSocket সাপোর্টসহ NGINX Ingress।

### কমান্ডসমূহ
```bash
# ১. ডকার ইমেজ বিল্ড ও পুশ করুন
docker build -t ghcr.io/your-username/arogyapos:latest .
docker push ghcr.io/your-username/arogyapos:latest

# ২. k8s/deployment.yaml-এ আপনার ইমেজ নাম এবং k8s/ingress.yaml-এ ডোমেইন আপডেট করুন
kubectl apply -f k8s/configmap.yaml
kubectl apply -f k8s/pvc.yaml
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml
kubectl apply -f k8s/ingress.yaml

# ৩. স্ট্যাটাস চেক করুন
kubectl get pods -l app=arogyapos
```

## API ও হেলথ এন্ডপয়েন্টস

| Method | Endpoint | বিবরণ |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Kubernetes Liveness Probe |
| `GET` | `/api/ready` | Kubernetes Readiness Probe (SQLite check) |
| `GET` | `/api/bootstrap` | সম্পূর্ণ ইনভেন্টরি, কাস্টমার, সেলস ও সেটিংস লোড |
| `POST` | `/api/medicines` | নতুন ওষুধ/ব্যাচ যোগ বা আপডেট |
| `DELETE` | `/api/medicines/:id` | ওষুধ মুছে ফেলা |
| `POST` | `/api/customers` | কাস্টমার যোগ বা আপডেট |
| `POST` | `/api/customers/:id/pay-due` | বকেয়া টাকা আদায় |
| `POST` | `/api/sales` | ইনভয়েস তৈরি ও অ্যাটমিক স্টক/বকেয়া আপডেট |
| `POST` | `/api/sync/batch` | অফলাইন কিউ থেকে ব্যাচ সিঙ্ক রিপ্লে |
| `POST` | `/api/backup/restore` | ব্যাকআপ ফাইল থেকে সম্পূর্ণ ডাটাবেজ রিস্টোর |
| `WS` | `/ws` | রিয়েল-টাইম মাল্টি-ডিভাইস সিঙ্ক ওয়েবসকেট |
